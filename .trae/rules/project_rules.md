# MyBlog 项目协作规则

## 每次修改必须完成的三件事

1. **更新 README 的「更新日志」**：在 `README.md` 末尾的 `## 更新日志` 中追加本次改动（日期、改了什么、涉及哪些文件）。
2. **提交到 git**：一次完整改动对应一个 commit，提交信息用中文说明改了什么，例如 `修复首屏文字裁切，地点改为 Beijing`。
3. **提交前验证**：至少跑通 `npm run build`；涉及视觉改动时在 `npm run preview` 下确认效果。

## 提交约定

- 只提交源码与文档，`node_modules/`、`dist/` 由 `.gitignore` 排除。
- 提交信息第一行简洁描述改动，必要时在正文中补充原因与验证方式。
- 不要混入与本意无关的格式化或文件改动。
